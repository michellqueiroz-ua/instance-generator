# Debugging scripts

- `python scripts/check_triangle_inequality.py` — Checks Maastricht's travel-time matrix for triangle-inequality violations (run from the repository root).
- `python scripts/diagnose_stops.py` — Diagnoses bus-stop assignments in Maastricht network data (run from the repository root).
- `python scripts/check_fix.py` — Checks bus-station assignments to Maastricht zones (run from the repository root).
- `python scripts/add_hospitals_to_existing_network.py "Location Name"` — Adds hospital data to an existing network (run from the repository root).
- `python scripts/assign_stations_maastricht.py` — Assigns bus stations to Maastricht zones (run from the repository root).
