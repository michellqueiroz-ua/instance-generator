# Legacy research scripts

Archived code from the research behind REQreate. It is **not part of the
installed package** and is not maintained or tested.

| Script | What it did | Data source (not included) |
|---|---|---|
| `trip_patterns_yellow.py`, `trip_patterns_green.py` | Trip-pattern analysis of New York taxi trips | [NYC TLC Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page) |
| `trip_patterns_chicago_TNP.py` | Ride-hailing trip patterns in Chicago | [Chicago Transportation Network Providers trips](https://data.cityofchicago.org/) |
| `trip_patterns_austin.py` | Trip patterns in Austin | City of Austin open data |
| `trip_patterns_sanfranciscobay.py` | Trip patterns in the San Francisco Bay Area | Bay Area open data |
| `trip_patterns_general.py` | Shared analysis (heatmaps, dispersion, similarity tests on real data) | the datasets above |
| `uber_movement.py` | Travel-speed regression | Uber Movement (service discontinued). Needs keras/tensorflow; does not run as-is. |
| `properties_synthetic_instances.py`, `population_density.py` | Statistical properties of generated instances | instances generated by REQreate |

None of the datasets are distributed here. If you obtain them, follow each
provider's terms of use.

The `rank_model` request distribution, which used to live in
`trip_patterns_general.py`, is part of the package: `REQreate/rank_model.py`.

## Running

Install the extra dependencies and run from this folder, so that
`distribution_fit.py` is importable:

```bash
pip install -e ".[analysis]"
cd legacy
python trip_patterns_yellow.py
```

`distribution_fit.py` is a small `scipy.stats` replacement for the `fitter`
package, which these scripts used before. `fitter` is GPL-3.0 and REQreate is
MIT.
